# Analog-Clock
A real time working analog clock made using pure HTML, CSS and JavaScript. 

## Features:
1. Displays the current local time dynamically.
2. Clock hand position is updated every second using JavaScript.

## Technologies Used: 
1. HTML - provides basic structure
2. CSS - clock hands UI and rotation animations
3. JavaScript - Time calculation and DOM manipulation

## How to Run:
1. Clone the repository making sure all files are in the same folder.
2. Run 'Clock.html' file.
